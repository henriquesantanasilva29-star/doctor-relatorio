O dicionário das definições. Todo número publicado nas telas do grupo carrega um chip que aponta para um verbete daqui. Número sem verbete é defeito, não estilo.

Verbetes

Cinco campos fixos, sempre na mesma ordem. O campo que mais evita erro é o último.

Pares que não somam

O leitor vai querer somar estes pares porque eles têm a mesma cara e a mesma moeda. MOTOR significa que o cálculo é outro — nenhuma troca de rótulo resolve.

Quando a definição mudou

Toda série que atravessa uma destas datas empilha dois motores sob um título só. As telas novas se recusam a calcular variação através delas.

Períodos

Uma implementação só, em comum.js. Esta tabela existe para você conferir de olho que a unificação de fato aconteceu.

Buracos conhecidos

Lista durável. Item consertado sai com data, não é apagado.

Chave no fragmento: o que vem depois do # o navegador não manda para servidor nenhum, nem para o GitHub que hospeda a página. Chave revogada devolve 404 igual a chave inexistente. Este repositório guarda a casca; o dado vive no banco.
